# Madhab Chandra Das — Academic Website

A responsive static website for GitHub Pages. No installation, build step, external fonts, or API keys are required.

## Publish on your existing GitHub Pages repository

1. Extract this ZIP on your computer.
2. Upload the contents of the `website` folder to the root of `MadhabCD.github.io`. The `index.html` file must be at the repository root, not inside an extra folder.
3. Commit the changes. If needed, set Settings > Pages > Deploy from a branch > main > / (root).
4. Open https://madhabcd.github.io/ after GitHub Pages finishes publishing.

The website has been prepared locally. No changes have been pushed to GitHub.

## Edit content

- `index.html`: biography, research, education, teaching, service and contact.
- `content.js`: publication entries and certificate records. Keep publication status current.
- `style.css`: colors, spacing, typography, desktop and mobile layouts.
- `script.js`: navigation, publication search and filters, certificate categories.
- `assets/profile.jpg`: portrait supplied by the site owner.
- `certificates/`: selected research, academic and training certificates.
- `downloads/`: Academic CV PDF, Word and LaTeX.

Published, accepted and under-review papers are displayed separately. The site uses selected publications, not a complete bibliography. Certificate links are public when you publish the website. Employee compliance training certificates are omitted. Keep a backup of your previous repository before replacing files.
